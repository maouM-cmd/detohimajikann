# 限界突破ゲームマスター

Haruki & のえちゃん向けの、行列待ち専用・スパルタ司会Webアプリです。

## 仕様

- 開始コマンド `ゲームスタート` に反応し、まず「どの地獄を味わいますか？1〜3」を案内
- 3つの特殊モードを収録
  1. 🤥 虚構（フィクション）解説選手権
  2. 🙇‍♂️ 緊急謝罪会見ごっこ
  3. 💌 限界ラブレター・チャレンジ
- 回答をDiscord風ログに積み上げ、`独断と偏見` で勝敗判定
- ランダム地獄選択ボタンあり

## 使い方

1. `index.html` を開く
2. コマンド欄で `ゲームスタート` を送信
3. 1〜3の地獄を選ぶ（またはランダム）
4. 回答を投稿して `独断で勝敗判定`
